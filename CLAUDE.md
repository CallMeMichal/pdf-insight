## Skille agenta

### Tracker zgłoszeń

Zgłoszenia są w GitHub Issues (CallMeMichal/pdf-insight), obsługiwane przez CLI `gh`. Zobacz `docs/agents/issue-tracker.md`.

### Etykiety triage

Domyślny słownik pięciu ról, stosowany jako etykiety GitHuba. Zobacz `docs/agents/triage-labels.md`.

### Dokumentacja domenowa

Jeden kontekst: jeden `CONTEXT.md` + `docs/adr/` w katalogu głównym repo. Zobacz `docs/agents/domain.md`.

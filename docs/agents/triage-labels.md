# Etykiety triage

Skille posługują się pięcioma kanonicznymi rolami triage. Ten plik mapuje te role na rzeczywiste nazwy etykiet używane w trackerze zgłoszeń tego repo.

| Etykieta w mattpocock/skills | Etykieta w naszym trackerze | Znaczenie                                      |
| ---------------------------- | --------------------------- | ---------------------------------------------- |
| `needs-triage`               | `needs-triage`              | Maintainer musi ocenić zgłoszenie              |
| `needs-info`                 | `needs-info`                | Czeka na dodatkowe informacje od zgłaszającego |
| `ready-for-agent`            | `ready-for-agent`           | W pełni opisane, gotowe dla agenta AFK         |
| `ready-for-human`            | `ready-for-human`           | Wymaga implementacji przez człowieka           |
| `wontfix`                    | `wontfix`                   | Nie będzie realizowane                         |

Gdy skill wspomina o roli (np. „nadaj etykietę gotowości dla agenta AFK”), użyj odpowiadającej jej nazwy etykiety z tej tabeli.

Edytuj prawą kolumnę, jeśli używasz innego słownictwa.
